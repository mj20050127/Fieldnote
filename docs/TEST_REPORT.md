## 重现方法

前置条件：按 README 安装依赖，MongoDB 监听 27017。

```powershell
.venv\Scripts\python.exe -m pytest backend/tests -q -p no:cacheprovider
.venv\Scripts\python.exe -m pip check
.venv\Scripts\python.exe scripts/export_openapi.py
npm.cmd --prefix frontend run generate:api
npm.cmd --prefix frontend run build
```

启动后端后，在 frontend 目录执行：

```powershell
npx.cmd playwright install chromium
npm.cmd run test:e2e
```

测试代码在 backend/tests 和 frontend/tests/workflow.spec.ts。后端测试创建独立的 fieldnote_test_* 库并清理。浏览器测试在当前开发库创建独立账号，不应指向生产实例。

## 并发和手算统计

并发使用 20 个工作线程请求真实 API 和 MongoDB，预置独立有效会话。

| 场景 | 请求数 | 实际保存数 |
|---|---:|---:|
| 不同账号 | 50 | 50 |
| 同账号禁止重复，不同请求编号 | 20 | 1 |
| 同账号相同请求编号和内容 | 20 | 1，返回同一答卷 |
| 同账号允许重复，不同请求编号 | 20 | 20 |

无非预期 500。本结果验证这些提交场景，不推算生产吞吐量，不声称长时间压测通过。

固定三份答卷：单选 A/B/A 得到 2/1/0；多选 XY/Y/XZ 得到 2/2/1；数字 10/20/留空得到有效 2 份、平均 15；无人填写的数字题平均值 null。原始值分页正确。

不同路径统计中，sessions 跳过 1 次，suggestions 跳过 2 次，other 到达但留空 2 次。跳过、到达和有效回答分开统计。
